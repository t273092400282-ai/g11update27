        تشريح جملة التحديث SQL وعلاقتها بكود بايثون
      


      

        
        

          UPDATE products
          
أمر التحديث: يحدد اسم الجدول المستهدف في قاعدة البيانات للتعديل عليه.

        


        

          SET column = ?
          
التعيين: يحدد الأعمدة والقيم الجديدة. عند تعديل عمودين نضع فاصلة SET size=?, price=?.

        


        

          WHERE condition
          
الشرط: أهم جزء لتحديد الصفوف المطلوبة فقط، وبدونه سيتم تعديل جميع صفوف الجدول بالكامل!

        


        

          connection.commit()
          
تأكيد الحفظ: كتابة التعديلات وحفظها نهائياً داخل ملف قاعدة البيانات RomaShop.db.

        


      

    


  


  
  

    

      

        

           تفكيك وشرح كود بايثون
        

        
      


      

        

          import sqlite3
          
استيراد مكتبة التعامل مع قواعد بيانات SQLite المضمنة في بايثون.

        

        

          connection = sqlite3.connect('RomaShop.db')
          
إنشاء قناة اتصال بملف قاعدة البيانات المسمى RomaShop.db.

        

        

          cursor = connection.cursor()
          
إنشاء المؤشر (Cursor) المسؤول عن إرسال أوامر SQL واستقبال النتائج.

        

        

          cursor.execute(...)
          
تنفيذ استعلام SQL مع تمرير المعاملات بأمان لحماية البيانات.

        

        

          connection.total_changes
          
خاصية تقرأ عدد السجلات التي تأثرت أو تم تعديلها منذ فتح الاتصال.
